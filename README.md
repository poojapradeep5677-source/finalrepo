
# Nutritrack
A Web application designed for tracking personal fitness goals, daily meal plans, and overall health progress.

---

## 📌 Features

- **Goal Tracking (`goals.html`)**: Set and track personal health and fitness targets.
- **Meal Management (`meals.html`)**: Log daily meal consumption and nutritional intake.
- **Progress Tracking (`progress.html`)**: Monitor progress over time with visual stats.
- **Summary Dashboard (`summary.html`)**: Overview of current goals, meals, and health stats.
- **User Authentication (`login.html`)**: Simple user login interface.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript
